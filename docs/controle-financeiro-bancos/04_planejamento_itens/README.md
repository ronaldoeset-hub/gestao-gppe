# 04 - Planejamento de itens

Banco mais parecido com a aba `Base Recursos` da planilha original.

Tabela Supabase sugerida:

- `financial_plan_items`

Campos essenciais:

- Unidade
- Programa
- Periodo
- Tipo de recurso
- Item
- Quantidade
- Unidade de medida
- Valor unitario
- Valor total
- Observacao

O valor total pode ser calculado no banco por `quantidade * valor_unitario`.
