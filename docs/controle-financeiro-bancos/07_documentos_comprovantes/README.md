# 07 - Documentos e comprovantes

Organiza arquivos usados para comprovar execucao financeira.

Tabelas Supabase relacionadas/sugeridas:

- `documents`
- `financial_documents`
- Storage bucket `documentos-gppe`

Categorias recomendadas:

- Nota fiscal
- Comprovante de pagamento
- Extrato bancario
- Plano de aplicacao
- Pesquisa de precos
- Parecer tecnico
- Ata
- Outro
